Це компанія (або організація), яка володіє [[Data Center|Data Centers]] і продає обчислювальні ресурси, сховище, мережу та ПЗ як послуги через Інтернет.

Як приклад: у електромережі provider — це енергокомпанія, яка тримає електростанції й лінії та продає кіловати. У стрімінгу — Netflix/Spotify, які тримають контент і інфраструктуру та продають доступ. У cloud — AWS/Azure/GCP, які тримають сервери й продають compute/storage/мережу.

У всіх цих прикладах принцип однаковий: **ти не володієш фабрикою ресурсів — ти орендуєш потужність у того, хто її вже збудував і обслуговує**.

==Cloud Provider== (Cloud Service Provider / CSP) у [[Cloud Computing]] — це сторона, яка:
1. Будує й утримує [[Data Center|Data Centers]] (сервери, мережа, живлення, охолодження)
2. Надає послуги через API / консоль / портал
3. Відповідає за фізичну інфраструктуру й (залежно від моделі) за частину ПЗ-стеку
4. Більє за споживання (pay-as-you-go) або за підписку

#### Великі публічні провайдери
1. AWS (Amazon Web Services)
2. Microsoft Azure
3. Google Cloud Platform (GCP)
4. Інші — Oracle Cloud, IBM Cloud, Alibaba Cloud, регіональні провайдери

#### Що типово продають
| Послуга | Приклади |
|---|---|
| Compute | [[Virtual Machine|VM]], containers, serverless |
| Storage | об'єктне сховище, диски, бекапи |
| Networking | VPC, балансувальники, CDN, DNS |
| Платформи / ПЗ | [[PaaS]], [[SaaS]], БД як сервіс, AI API |

#### Відповідальність: хто за що
| | Provider | Ти (клієнт) |
|---|---|---|
| Фізичні сервери, DC | ✅ | ❌ |
| Мережа всередині DC | ✅ | ❌ (конфігуруєш логічно) |
| ОС / патчі на VM ([[IaaS]]) | частково / ти | ✅ (залежить від моделі) |
| Твій код і дані | ❌ | ✅ |
| Доступ користувачів, ключі, права | ❌ | ✅ |

*Shared responsibility: провайдер тримає cloud, ти відповідаєш за те, що там запускаєш і як туди пускаєш людей.*

#### Зв'язок з моделями послуг
Провайдер може продавати один і той самий [[Data Center]] під різними «упаковками»:
1. [[IaaS]] — «ось тобі VM, роби що хочеш»
2. [[PaaS]] — «кинь код, ми піднімемо рантайм»
3. [[SaaS]] — «ось готовий продукт, просто користуйся»

*Cloud Provider = власник фабрики ресурсів; ти — орендар потужності через Інтернет.*
