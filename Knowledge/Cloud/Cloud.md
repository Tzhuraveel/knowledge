Сервери, до яких підключаються через Інтернет для зберігання даних, запуску програм чи використання програмного забезпечення, замість використання власних серверів або локального комп'ютера.

Майже всі люди на землі користуються Cloud, навіть не знаючи про це. Instagram, TikTok, Gmail, Google Drive, YouTube і так далі відносяться до Cloud.

У всіх цих прикладах принцип однаковий: **дані, ПЗ і обчислення живуть не на твоєму девайсі, а на серверах у [[Data Center|Data Centers]] — доступ до них іде через Інтернет**.

==Cloud== у побуті — саме це: сервіси на кшталт Drive, Gmail, Instagram. Технічно модель надання ресурсів через мережу — це [[Cloud Computing]].

#### Види cloud (де живуть ресурси)
1. **Public** — спільна інфраструктура провайдера (AWS, Azure, GCP); ти орендуєш шматок
2. **Private** — cloud під одну організацію (свій [[Data Center|DC]] або виділене середовище)
3. **Hybrid** — мікс: частина on-prem / private, частина в public cloud

#### Пов'язані поняття
1. [[Data Center]] — фізичне місце, де стоять сервери cloud
2. [[Cloud Computing]] — модель «ресурси як послуга»
3. [[Cloud Provider]] — хто продає ці ресурси
4. [[IaaS]] / [[PaaS]] / [[SaaS]] — рівні послуг (інфра → платформа → готове ПЗ)
5. [[Virtualization]] → [[Virtual Machine]] — як на одному сервері крутять багато ізольованих машин
6. [[Network]] / [[Host (network)]] — без мережі й кінцевих пристроїв cloud недоступний

*Cloud у розмові = «десь у інтернеті на чужих серверах». Cloud Computing = як саме це організовано технічно.*
