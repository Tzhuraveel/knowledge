Це програмна емуляція комп'ютера: повноцінна (з точки зору гостя) система з власною ОС, яка працює поверх фізичного сервера завдяки [[Virtualization]].

Як приклад: окрема кімната в гуртожитку — свої двері й правила, але стіни, електрика й дах спільні з будівлею. Орендований автомобіль у каршерингу — для тебе «твоя машина», хоча автопарк належить компанії. Virtual desktop — ти бачиш Windows/Linux, ніби це окремий ПК, хоча CPU й RAM насправді шматок чужого сервера.

У всіх цих прикладах принцип однаковий: **для тебе це окремий комп'ютер; фізично — ізольована частка ресурсів на спільному залозі**.

==Virtual Machine== (VM / Virtual Machine) складається з:
1. Virtual CPU (vCPU)
2. Virtual memory (RAM)
3. Virtual disks
4. Virtual network interfaces (vNIC)
5. Guest OS — Windows, Linux тощо

Під капотом цим керує **hypervisor** — частина [[Virtualization]].

#### VM vs фізичний сервер
| | Фізичний сервер | Virtual Machine |
|---|---|---|
| Залізо | Своє | Спільне, поділене |
| Створення | Тижні / закупка | Хвилини |
| Масштаб | Купувати нове | Підкрутити розмір / клонувати |
| Ізоляція | Фізична | Логічна (hypervisor) |

#### Де ти з цим стикаєшся
1. [[IaaS]] у cloud — EC2 instance, Azure VM, GCE instance ≈ VM
2. Локально — VirtualBox, VMware, Hyper-V для тестів і лабораторій
3. Сервери компаній — багато VM на кількох потужних хостах замість «1 сервіс = 1 залізний ящик»

#### VM vs container (коротко)
| | VM | Container |
|---|---|---|
| Що ізолює | Цілу машину + свою ОС | Процеси поверх спільної ОС хоста |
| Вага | Важча | Легша |
| Старт | Повільніший | Швидший |

*VM — «комп'ютер у комп'ютері»; container — «ізольований процес із файловою системою». У [[Cloud Computing]] використовують і те, і те.*

#### Зв'язок з іншими поняттями
1. [[Virtualization]] — технологія, яка робить VM можливою
2. [[IaaS]] — типовий спосіб орендувати VM у [[Cloud Provider]]
3. [[Host (network)]] — з точки зору мережі VM також є host'ом (має IP, шле/приймає трафік)

*Virtual Machine = virtual computer з власною ОС на спільному фізичному сервері.*
