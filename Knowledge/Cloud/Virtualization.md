Це технологія, яка дозволяє на одному фізичному комп'ютері (або сервері) запускати кілька ізольованих virtual environments, кожне з яких виглядає як окремий комп'ютер.

Як приклад: офісна будівля з багатьма кабінетами — одна будівля, багато ізольованих робочих місць. Жорсткий диск, розбитий на розділи — один диск, кілька «окремих» томів. Багатокімнатна квартира — спільні стіни й комунікації, але кімнати можна здавати різним орендарям.

У всіх цих прикладах принцип однаковий: **одна фізична база ділиться на кілька логічно незалежних частин, які майже не заважають одна одній**.

==Virtualization== (Virtualization) у IT — саме це розділення. Найчастіше йдеться про:
1. Compute virtualization — кілька [[Virtual Machine|VM]] на одному сервері
2. Storage virtualization — логічні томи поверх фізичних дисків
3. Network virtualization — virtual networks / VLAN / overlay поверх фізичної мережі

#### Як це працює (спрощено)
1. Є фізичний сервер (CPU, RAM, диски, NIC)
2. На ньому працює **hypervisor** — ПЗ, яке ділить ресурси
3. Hypervisor створює кілька гостьових систем ([[Virtual Machine|VM]])
4. Кожна VM думає, що має «свій» процесор, пам'ять і диск

#### Навіщо
1. Краще використання заліза — один сервер не простоює на 5% CPU
2. Ізоляція — падіння/зламання однієї VM не обов'язково вбиває інші
3. Швидке створення/знищення середовищ (хвилини замість закупівлі сервера)
4. Основа сучасного [[Cloud Computing]]: [[Cloud Provider]] продає тобі шматок virtualized hardware, а не цілий фізсервер

#### Типи hypervisor (коротко)
| Тип | Де живе | Приклад |
|---|---|---|
| Type 1 (bare metal) | Прямо на залозі | ESXi, Hyper-V, Xen, KVM |
| Type 2 (hosted) | Як програма поверх ОС | VirtualBox, VMware Workstation |

*У cloud [[Data Center|Data Centers]] майже завжди Type 1.*

#### Зв'язок з Cloud
Без [[Virtualization]] [[IaaS]] у звичному вигляді не існує: ти отримуєш не «стіну серверів на кожного клієнта», а ізольовані [[Virtual Machine|VM]] (або containers — легша форма ізоляції) на спільній інфраструктурі провайдера.

*Virtualization = одна фізика → багато логічних комп'ютерів. Конкретний «логічний комп'ютер» — це [[Virtual Machine]].*
