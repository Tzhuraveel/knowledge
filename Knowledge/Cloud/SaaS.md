Це модель [[Cloud Computing]], де ти користуєшся готовим програмним продуктом через Інтернет — без встановлення інфраструктури, ОС чи платформи для деплою.

Як приклад: ресторан — ти не орендуєш кухню й не наймаєш кухарів, просто замовляєш готову страву. Netflix — не ставиш свій відеосервер, просто дивишся. Gmail — не адмініструєш поштовий сервер, просто відкриваєш лист у браузері.

У всіх цих прикладах принцип однаковий: **продукт уже зібраний і обслуговується постачальником — ти лише користуєшся ним (часто за підписку)**.

==SaaS== (Software as a Service) — найвищий рівень cloud-послуг з погляду зручності для кінцевого користувача. [[Cloud Provider]] або софт-компанія дає:
1. Готовий застосунок (UI + бекенд)
2. Хостинг, оновлення, бекапи, масштабування
3. Доступ через браузер / мобільний клієнт / API

Ти керуєш (зазвичай):
1. Своїми обліковими записами й правами користувачів
2. Контентом / даними, які вводиш у продукт
3. Налаштуваннями в межах того, що дозволяє продукт
4. Інтеграціями (SSO, webhooks, API) — якщо вони є

#### Що на тобі vs на провайдері
| Шар | Хто керує |
|---|---|
| Інфраструктура, ОС, платформа, код продукту | Provider |
| Конфіг і дані клієнта | Ти (у межах продукту) |
| Хто має доступ до акаунта | Ти |

#### Типові приклади
1. Gmail, Google Drive, Microsoft 365
2. Slack, Notion, Figma, Salesforce
3. GitHub, Dropbox, Zoom

*Більшість cloud-сервісів, якими люди користуються щодня, — це саме SaaS.*

#### Порівняння з іншими моделями
| | [[IaaS]] | [[PaaS]] | SaaS |
|---|---|---|---|
| Що отримуєш | VM, диски, мережа | Платформа для коду | Готовий застосунок |
| Фокус | Інфра | Розробка | Користування |
| Контроль | Максимум | Середній | Мінімум |
| Приклад | EC2 | App Service / Heroku | Gmail |

*SaaS = оренда готового ПЗ. Якщо треба свій код на чужій платформі — [[PaaS]]; якщо треба свій сервер «під ключ інфри» — [[IaaS]].*
