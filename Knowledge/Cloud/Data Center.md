Це спеціалізована будівля (або частина будівлі чи декілька будівель), де стоять сервери, сховища та мережеве обладнання — фізичне місце, звідки «живуть» інтернет-сервіси й [[Cloud]].

Як приклад: склад логістичної компанії — не магазин для відвідувачів, а місце, де зберігають і сортують товар, щоб він швидко доходив до клієнтів. Електропідстанція — не «розетка вдома», а вузол, де концентрують потужність для багатьох споживачів. Банківське сховище — захищене приміщення під цінності, з охороною, резервним живленням і контролем доступу.

У всіх цих прикладах принцип однаковий: **критична інфраструктура зібрана в одному захищеному місці, щоб надійно обслуговувати багато клієнтів віддалено**.

==Data Center== (Data Center / DC) — саме таке місце для IT. Усередині типово є:
1. Сервери ([[Host (network)|hosts]]) — рахують, зберігають, віддають дані
2. Мережа ([[Network]]) — комутатори, маршрутизатори, лінки в Інтернет
3. Зберігання — диски, СХД, стрічки/бекапи
4. Живлення — UPS, генератори (щоб не падало при відключенні світла)
5. Охолодження — кондиціонери / холодопостачання (сервери сильно гріються)
6. Фізична безпека — доступ, камери, пожежогасіння

*Без Data Center немає де стояти серверам [[Cloud Provider]]. Cloud — логічна послуга; DC — цегла, стійки й кабелі під нею.*

#### Навіщо їх багато і по світу
1. Близькість до користувачів — менша затримка (latency)
2. Відмовостійкість — якщо один DC впав, інший може підхопити
3. Закони / регіони — дані інколи мають лишатися в певній країні

#### Зв'язок з Cloud
1. [[Cloud]] / [[Cloud Computing]] — ти користуєшся сервісами; фізично вони крутяться в DC
2. [[Cloud Provider]] — володіє (або орендує) багато DC і продає їхню потужність як послугу
3. [[Virtualization]] → [[Virtual Machine]] — всередині DC один фізсервер ділиться на багато VM для різних клієнтів
4. [[IaaS]] — ти орендуєш шматок потужності саме з цих DC

|                                      | On-prem (свій сервер у офісі) | Data Center / Cloud              |
| ------------------------------------ | ----------------------------- | -------------------------------- |
| Де стоїть                            | У тебе                        | У провайдера / колокейшн         |
| Хто крутить живлення, холод, охорону | Ти                            | Оператор DC / [[Cloud Provider]] |
| Масштаб                              | Обмежений кімнатою            | Стійки × тисячі серверів         |

*Data Center = фізичний «будинок для серверів». Cloud = спосіб здавати потужність цього будинку клієнтам через Інтернет.*
