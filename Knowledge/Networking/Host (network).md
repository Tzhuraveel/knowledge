> Це кінцевий учасник Internet Network, який генерує, споживає або обробляє ресурси.

Як приклад: у дорожній мережі host — це місто або склад, звідки вирушають і куди прибувають вантажі. У електричній мережі — споживач або електростанція, які виробляють чи використовують енергію. У соціальній мережі — конкретна людина, яка пише повідомлення і читає відповіді.

У всіх цих прикладах принцип однаковий: **є учасник, заради якого існує мережа зв'язків — він створює або споживає те, що мережа переносить**.

==Host== (Host / End Device) у комп'ютерній мережі працює за тим самим принципом. Це будь-який обчислювальний девайс, який:
1. Generate Data (відправляє запити, файли, повідомлення)
2. Consume Data (отримує відповіді, завантажує контент, користується сервісами)
3. Run Applications (браузер, пошта, серверні програми, ігри)

*Саме hosts є джерелом і призначенням трафіку в мережі — маршрутизатори та комутатори лише доставляють його між ними.*

#### Що може бути host'ом ?
1. Клієнтські девайси — ПК, ноутбуки, смартфони, планшети
2. Сервери — вебсервери, файлові сервери, поштові сервери, DNS
3. IoT / спецпристрої — камери, принтери, сенсори, смарт-ТВ

#### Чим host відрізняється від мережевого обладнання ?
| | Host | Network Device |
|---|---|---|
| Роль | Джерело / отримувач даних | Передача / маршрутизація даних |
| Приклади | ПК, сервер, телефон | Router, Switch, Access Point |
| Мета | Запускати застосунки та обмінюватись даними | З'єднувати hosts між собою |

*Без hosts мережа не має сенсу: немає кому обмінюватися даними.*
